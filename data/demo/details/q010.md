# Example 010 – Suspicious DNS Queries

**Question**  
List all DNS queries from the last 2 hours that contain the word 'malware' or 'phishing' in the query field

**Generated Query**
```slaql
from last 2h
| where event_type == "dns" and (query like "*malware*" or query like "*phishing*")
| fields timestamp, source_ip, query, hostname
```

**Note:** The field `query` is used for DNS query content.
