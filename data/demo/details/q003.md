# Example 003 – PowerShell with High Severity

**Question**  
List all processes that contain 'powershell' with high or critical severity between June 1 and June 2 2024

**Generated Query**
```slaql
from 2024-06-01 to 2024-06-02
| where process like "*powershell*" and severity in ("high", "critical")
| fields timestamp, user, hostname, process, rule_name
```

**Step-by-step reasoning**
1. Explicit date range
2. Wildcard match on process name
3. Severity filter using `in`
4. Select relevant fields only
