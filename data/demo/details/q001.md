# Example 001 – High Severity Logins

**Question**  
Show me all high severity login events from the last 24 hours grouped by user and source IP

**Generated Query**
```slaql
from last 24h
| where event_type == "login" and severity == "high"
| stats count() by user, source_ip
| sort count desc
```

**Step-by-step reasoning**
1. Time range: last 24 hours → `from last 24h`
2. Filter for login events with high severity
3. Aggregate count grouped by user and source_ip
4. Sort descending by the count
