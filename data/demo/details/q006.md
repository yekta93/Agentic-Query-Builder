# Example 006 – Critical Malware by Hostname

**Question**  
Count the number of critical malware events per hostname in the last 48 hours and show the top 10

**Generated Query**
```slaql
from last 48h
| where event_type == "malware" and severity == "critical"
| stats count() by hostname
| sort count desc
| limit 10
```

**Reasoning**
1. Time range: last 48 hours
2. Filter malware + critical severity
3. Aggregate count by hostname
4. Sort descending and keep top 10
