# Example 007 – Blocked SSH/RDP Attempts

**Question**  
Show all blocked firewall events from the last 12 hours where the destination port is 22 or 3389

**Generated Query**
```slaql
from last 12h
| where event_type == "firewall" and action == "blocked" and dest_port in (22, 3389)
| fields timestamp, source_ip, dest_ip, dest_port, rule_name, user
```

**Note:** `dest_port` is treated as a useful extension field for firewall events.
