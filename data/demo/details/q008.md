# Example 008 – Brute-force Style Failed Logins

**Question**  
Find users who had more than 5 failed login attempts in the last 6 hours

**Generated Query**
```slaql
from last 6h
| where event_type == "login" and action == "blocked"
| stats count() by user
| where count > 5
| sort count desc
```

**Reasoning**
- Filter failed/blocked logins
- Aggregate per user
- Post-aggregation filter on count > 5
