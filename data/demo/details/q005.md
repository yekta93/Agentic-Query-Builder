# Example 005 – Critical Internal Firewall Events

**Question**  
Show critical firewall events from the last 6 hours where the source IP starts with 10.0

**Generated Query**
```slaql
from last 6h
| where event_type == "firewall" and severity == "critical" and source_ip like "10.0*"
| fields timestamp, source_ip, dest_ip, action, rule_name
```
